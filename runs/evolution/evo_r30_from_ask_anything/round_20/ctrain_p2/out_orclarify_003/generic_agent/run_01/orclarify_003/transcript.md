## Turn 1 - Generic Agent

QUESTION: Is the 20-hour overtime limit a per-worker cap that applies to each individual worker, or is it a total cap for the entire workforce per month?

## Turn 1 - User Simulator

It is a per-worker cap. Each individual worker can work at most 20 overtime hours in a given month.

## Turn 2 - Generic Agent

QUESTION: Is the 10,000-unit minimum ending inventory requirement a hard constraint that must be strictly satisfied, or is it a soft target that can be violated if doing so increases total net profit

## Turn 2 - User Simulator

It is a hard constraint. The ending inventory at the end of June must be at least 10,000 units.

## Turn 3 - Generic Agent

QUESTION: Is the demand forecast for each month a hard minimum that must be fully satisfied (with any shortfall carried as backorders), or is it a target where unmet demand can be permanently lost

## Turn 3 - User Simulator

The demand forecast is a hard minimum that must be fully satisfied. Any shortfall in a given month is carried as backorders and must be met in subsequent months.
