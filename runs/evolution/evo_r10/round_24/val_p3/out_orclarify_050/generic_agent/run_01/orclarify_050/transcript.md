## Turn 1 - Generic Agent

QUESTION: Is there a limit on how many units can be purchased in any single month (a monthly purchase budget or supplier cap), or can you buy any quantity you want at that month's buy price?

## Turn 1 - User Simulator

There is no limit on how many units can be purchased in any single month. You can buy any quantity you want at that month's buy price.

## Turn 5 - Generic Agent

## Turn 5 - User Simulator

## Turn 6 - Generic Agent

QUESTION: In a given month, can you both buy and sell units, and does the month's ending inventory count the units bought that same month as available to sell that same month (i.e., buy and sell happen within the month, so ending stock = opening + bought − sold)?

## Turn 6 - User Simulator

Yes, you can both buy and sell units in a given month. The units bought that same month are available to sell that same month. Ending stock equals opening stock plus units bought minus units sold.
